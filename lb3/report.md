## 4. Принятые решения по пагинации, лимитам и повторам

- **Пагинация:** `limit=30`, `skip` инкрементируется на фактическую длину страницы. Остановка при пустой странице или достижении `total`. Предохранитель: `max_pages=20`.
- **Лимиты:** пауза между запросами 0.6 с (класс `RateLimiter`).
- **Повторы:** только для 429 и 5xx. Экспоненциальная задержка `2^attempt + random(0,1)`. Для 4xx повторы запрещены.
- **Журнал сбора:** `collection_log.csv` с полями: номер страницы, URL, параметры, код ответа, число записей, длительность, отметка времени.

## 6. Описание no-code сценария (n8n)

**Workflow:** `lb3(n8n).json`

**Узлы:**
1. **Schedule Trigger** — запуск каждый час.
2. **HTTP Request** — GET `https://dummyjson.com/comments` с параметрами `limit=30`, пагинация через `skip = $pageCount * 30`. Остановка при `$response.body.comments.length === 0`. Включён полный ответ (`statusCode`, `body`).
3. **IF** — проверка `{{ $json.statusCode }} != 200`. True-ветка → **Code in JavaScript** вывод ошибки в консоль→ **Stop and Error** с сообщением об ошибке. False-ветка → **Split Out**.
4. **Split Out** — разворачивает массив `body.posts` в отдельные элементы.
5. **Edit Fields (Set)** — преобразование полей:
   - `post_id` ← `id`
   - `title_clean` ← очищенный rex-выражением `title`
   - `likes` ← `likes`
   - `popularity_score` ← `likes - dislikes` (вычисляемое)
   - `collected_at` ← текущая дата сбора
6. **Convert to File** — преобразование в CSV (`posts_export.csv`, заголовки включены).
7. **Read/Write Files from Disk** — сохранение в `/files/comments_export.csv` (папка смонтирована с хоста).


**Результат:** `nocode/posts_export.csv` .

## 8. Правовая и этическая оценка

- **Условия использования API:** DummyJSON — публичный mock-API для тестирования. Регистрация не требуется. Запрещено использовать для production-трафика. Данные не сохраняются на сервере.
- **Наличие персональных данных:** В `/users` содержатся вымышленные данные (email, телефон, адрес, SSN и т.д.). Они не принадлежат реальным лицам, поэтому обработка не подпадает под 152-ФЗ.
- **Основание обработки по 152-ФЗ:** отсутствует, так как субъекты данных не существуют.
- **Срок хранения:** Неограничен, так как данные учебные.
- **Этическая оценка:** сбор этичен, так как API публичный, данные фиктивные, нагрузка на сервер минимальна (паузы между запросами).
